# Nuru TV downloads

Installers and update files for Nuru TV. Installed apps check this page for updates.

Download the latest version from **Releases**:

| File | For |
|---|---|
| `Nuru-TV_<version>_x64-setup.exe` | Windows (almost every laptop) |
| `Nuru-TV_<version>_x86-setup.exe` | Older 32-bit Windows |
| `Nuru-TV_<version>_Mac-Apple-silicon.dmg` | Mac with Apple silicon |
| `Nuru-TV_<version>_arm64.apk` | Android phones and Android TV |
| `Nuru-TV_<version>_armv7.apk` | Older Android phones |
