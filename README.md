# Nuru TV downloads

Installers and update files for Nuru TV. Installed apps check this page for updates.

Download the latest version from **Releases**:

| File | For |
|---|---|
| `Nuru-TV_<version>_x64-setup.exe` | Windows (almost every laptop) |
| `Nuru-TV_<version>_x86-setup.exe` | Older 32-bit Windows |
| `Nuru-TV_<version>_Mac-Apple-silicon.dmg` | Mac with Apple silicon |
| `Nuru-TV_<version>_arm64.apk` | Android phones and Android TV |
| `Nuru-TV_<version>_armv7.apk` | Older Android phones |

## Source code

Nuru TV is free software under the GNU General Public License, version 3 or later (see `LICENSE`). It is based on [Nyx Player](https://github.com/kunai974/nyx-player).

The complete source for each public version is attached to its release as `Nuru-TV_<version>_source.tar.gz`. Build instructions are in `README.md` and `docs/BUILDING.md` inside the archive.

If you received Nuru TV 1.3.4 or earlier and want the source for that version, [open an issue](https://github.com/mmmholy/nuru-tv-releases/issues/new?title=Source%20request) naming the version and we will provide it.
